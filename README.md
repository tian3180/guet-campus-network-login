# GUET 校园网快捷登录

为桂林电子科技大学校园网准备的便捷登录工具：连接校园网后，通过快捷指令或脚本发起认证，减少反复打开网页、填写账号密码的操作。

| 使用设备 | 方式 | 常用入口 |
| --- | --- | --- |
| iPhone（iOS） | 苹果原生快捷指令 | 控制中心、操作按钮、主屏幕 |
| iPad（iPadOS） | 与 iPhone 相同的快捷指令 | 控制中心、主屏幕 |
| Mac（macOS） | 与 iPhone 相同的快捷指令 | 程序坞、键盘快捷键 |
| Linux | Bash 脚本 | 终端、桌面启动器 |

> iPhone、iPad 和 Mac 使用同一个快捷指令，不需要安装第三方 App。Linux 使用本仓库的脚本。不同校园网接入环境及系统版本可能影响运行效果，具体请以实际测试为准。

## 开始使用

先将设备连接到学校提供的校园网 Wi-Fi，再根据设备选择下面的使用方式。首次运行时，如果系统询问是否允许快捷指令访问网络，请按提示允许。

### iPhone、iPad 和 Mac：安装与配置

1. 打开 [GUET 校园网自动登录快捷指令安装链接](https://www.icloud.com/shortcuts/7b8e7e8aedd346d791def56cc4ca1114)。
2. 在「快捷指令」App 中添加该指令。使用同一 Apple 账户并开启快捷指令的 iCloud 同步后，也可以在其他设备上使用。
3. 打开指令的编辑界面，按开头注释依次修改三个文本框：校园网账号、密码、运营商代码。
4. 连接校园网后，运行快捷指令，并根据提示检查联网情况。

如果发布者设置了导入问题，也可以按导入时的提示填写配置。输入的密码会保存在本人的快捷指令中，**不要分享已经填写个人信息的副本**。

| 网络类型 | 运营商文本框填写 |
| --- | --- |
| 广电 | `glgd` |
| 中国移动 | `cmcc` |
| 中国联通 | `unicom` |
| 中国电信 | `telecom` |
| 校园网账号 | 留空，参见下方说明 |

运营商代码请使用小写字母。校园网账号留空的情况目前仍需在实际环境中验证；如果无法登录，请先使用校园网官方登录页面确认账号类型。不同版本的系统界面名称可能略有差异。

### iPhone：控制中心和操作按钮

**控制中心一键运行**

1. 打开控制中心，点击左上角的「+」，然后选择「添加控件」。
2. 找到并添加「快捷指令」控件，选择本项目的校园网快捷指令。
3. 以后连接校园网后，下拉打开控制中心，点击该控件即可运行。

**使用手机左侧的操作按钮**

1. 在支持操作按钮的 iPhone 上，打开「设置」→「操作按钮」。
2. 切换到「快捷指令」，选择本项目的校园网快捷指令。
3. 连接校园网后，长按机身左侧的操作按钮即可运行。

操作按钮仅适用于配备该按钮的机型，例如 iPhone 15 Pro 和 iPhone 15 Pro Max；普通的响铃／静音拨片或音量键不能按上述方法设置。控制中心的控件功能也取决于系统版本。

还可以在快捷指令的详情中选择「添加到主屏幕」，像打开 App 一样点击运行。

### iPad：控制中心和主屏幕

**控制中心：**打开控制中心，点击「+」→「添加控件」，添加「快捷指令」控件并选择本项目指令；之后点击控件即可运行。控件的可用性取决于 iPadOS 版本。

**主屏幕：**在「快捷指令」中打开该指令的详情，选择「添加到主屏幕」并确认。之后连接校园网，点击主屏幕上的图标即可运行。

### Mac：程序坞和键盘快捷键

**程序坞：**在「快捷指令」App 中选中校园网快捷指令，选择菜单栏「文件」→「添加到程序坞」。以后连接校园网后，点击程序坞中的图标即可运行。

**键盘快捷键：**打开该快捷指令的编辑界面，在右侧「详细信息」中选择「添加键盘快捷键」，按下想使用的组合键。之后使用该组合键即可运行；请避免与其他应用的快捷键冲突。

### Linux：终端运行

Linux 版根据原 macOS Shell 脚本调整，使用 Bash、`curl`、`base64` 和 `tr`。目前尚未在 Linux 校园网环境实测；不同发行版、网络代理及校园网配置可能影响结果。

1. 下载本仓库中的 `logging_guet-linux.sh` 和 `guet-config.example.sh`，放到同一个目录。
2. 打开终端，进入该目录，创建个人配置文件并限制其访问权限：

   ```bash
   cp guet-config.example.sh guet-config.sh
   chmod 600 guet-config.sh
   ```

3. 使用文本编辑器打开 `guet-config.sh`，填写 `GUET_ACCOUNT`、`GUET_PASSWORD` 和 `GUET_ISP`；运营商代码见上表。请将它当作包含密码的私人文件保存。
4. 连接校园网，在相同目录中运行：

   ```bash
   bash logging_guet-linux.sh
   ```

脚本会先尝试检测联网状态，已联网时跳过认证；否则获取认证参数、发送登录请求，再尝试复查联网状态。联网检测依赖外部服务，代理、多网卡或服务不可达时可能出现误判，遇到异常请用浏览器确认。

如果经常使用 Linux 图形桌面，可以在桌面环境中新建启动器，运行 `bash "/脚本所在目录/logging_guet-linux.sh"`，将路径替换为实际路径，并选择在终端中运行以查看结果；具体设置方式因桌面环境而异。配置保存在脚本同目录的 `guet-config.sh` 中。

## 常见问题

**提示未能确认联网，但实际上已经可以上网？**

先用浏览器打开其他网站确认；联网检测可能受到检测网站、代理、VPN 或蜂窝网络的影响。在 iPhone 上排查时，可以暂时关闭蜂窝数据，确保正在通过校园网验证。

**未获取到认证参数或登录失败？**

确认已连接校园网 Wi-Fi，检查账号、密码和运营商代码，必要时先在浏览器打开校园网认证页面。校园网地址或认证规则发生变化时，工具可能需要更新。

**为什么 Linux 运行时提示缺少依赖？**

请使用所在发行版的软件包管理器安装提示中缺少的工具；`base64` 和 `tr` 通常由 coreutils 提供。脚本需要在 Bash 中运行。

## 隐私与分享

- 快捷指令的三个文本框和 Linux 的个人配置文件会保存明文密码。请不要提交、截图公开或分享已经填写个人信息的文件和指令；仓库提供的 `.gitignore` 会忽略默认的 `guet-config.sh`，但不会阻止手动上传或分享。
- 认证请求使用校园网接口提供的 HTTP 和 Base64 编码。Base64 不是加密；请根据自己的安全需求决定是否使用，并避免在不可信网络使用。
- 发布快捷指令前，请清空账号、密码及其他个人数据，或为对应字段设置导入问题；分享后应通过安装链接检查收到的副本，确认其中没有个人信息。不要公开原始 macOS 脚本或包含凭据的截图。
- Linux 脚本保留原脚本的账号格式和密码处理方式，默认使用 `http://1.2.3.4/` 触发认证跳转；其适用性、校园网账号留空时的格式和联网判断仍需在目标环境实测。
